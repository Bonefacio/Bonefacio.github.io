Veterinary reference

Clear clinical knowledge, close at hand.

AnatVet is a veterinary educational and clinical reference application designed to support structured access to veterinary information, patient workflow tools, medication references, dose calculations, anatomy, laboratory data and clinical learning materials.

The application is intended as an educational and reference tool. It does not replace a professional veterinary examination, diagnosis or clinical decision-making.
